# V2 M5 — Navigation and scalability

**Date:** 2026-10-29. **Baseline:** verified main `d2845b46c936360c4865e0529e53ab411d028f31` (M4 PR #81 squash merge `f22f24e` plus mechanical continuity refresh). **Branch:** `feature/v2-m5-navigation-scalability`. **Requirements:** BE-U01/U02/U03/U04, BE-S03/S05, BE-L03/L04 and the M5 exit gate in `docs/v2/ROADMAP.md`.

## Implementation boundaries

1. **Subtree focus.** The Branch Editor can isolate a chosen module or nested subtree from its canonical preorder projection, even if its ancestors were collapsed. Exit restores the previous selected module, collapsed IDs, active rendering window and vertical/horizontal scroll positions. It does not create a second report hierarchy. Focus can be entered from a module's right-click menu or the navigation toolbar.
2. **Native search.** Casefold search reads canonical module titles, headings, paragraphs, photo captions, tables and the report title, **including collapsed nodes**. A match is located by stable ID; revealing it expands only required ancestors and brings the containing window and card into view. Search never reads browser HTML, files or customer external services. F3 cycles matches. Pending drafts block any navigation requiring a destructive widget rebuild; a simple visible module jump may still scroll/select without rebuilding.
3. **Workspace zoom, pan and fit.** Zoom is an ephemeral 55–160% card typography/presentation adjustment, with Ctrl+wheel and toolbar/keyboard controls. Fit derives a conservative width ratio from the active projection and viewport. Shift+wheel, keyboard and toolbar commands pan horizontally when needed. **No print size, image layer geometry, project schema or DOCX/PDF dimensions are modified.** No visible workspace or inline-editor scrollbar is introduced.
4. **Bounded live Qt widgets.** Only up to 120 consecutive canonical preorder rows create editable Qt cards at a time. Previous/next window commands, boundary wheel/touchpad navigation and search/TOC jumps move between deterministic windows without creating an unbounded population of live editor widgets. Mixed sibling indices remain canonical; a window starting inside a module has a visible owner breadcrumb. Collapsed summaries still come from canonical descendant counts and may cover any supported safe nesting depth. Active drafts block window changes instead of being lost. This is an explicit bounded-widget approach rather than a fake independent document paginator.
5. **Accessibility and keyboard.** Separate Branch Navigation toolbar provides Find (Ctrl+F), Next match (F3), Focus/Exit, Zoom/Fit, horizontal Pan, Previous/Next window and module-selection actions. Existing context menus and validated keyboard movement/indent/outdent/duplicate/delete commands remain intact and use the canonical CommandGateway. Hover/scroll/caret native editor behavior and all mixed content rendering remain controlled by Qt layouts.
