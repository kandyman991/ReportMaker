## Findings and corrections

- **PR19-F01 — HIGH — non-transactional annotation dragging / Redo invalidation.** A mere selection press called `checkpoint()` and cleared Redo even if nothing changed; dragging an annotation against the image edge clamped endpoints independently, permanently deforming lines, rectangles and pen strokes. Deferred checkpoint until actual movement, made all vertices translate rigidly, and derived motion from press-start geometry to prevent drift after reaching the boundary. One drag is one Undo entry; click-only selection preserves Redo.
- **PR19-F02 — MEDIUM — image-coordinate leakage through rotated transparent padding.** `QImage.transformed` expands the canvas for arbitrary straighten angles. Clicking padded corners inverse-mapped outside the crop, then clamped to an unrelated full-source location, allowing invisible/misaligned annotations. Reject coordinates outside the untransformed crop image, preserve source-relative annotation anchors, and verify inverse mapping across crop/90° rotation/straightening/flip combinations.
- **PR19-F03 — MEDIUM — malformed annotation kind escapes schema validation.** A v3 photo mark with a JSON array/dict `kind` reached `kind in frozenset` and raised `TypeError`, not the recoverable `ValueError` expected by project Open. Explicitly validate string type before membership and exercise corrupt ZIP payloads without touching the source archive.
- **PR19-F04 — MEDIUM — schema downgrade ambiguity.** The original v1/v2 loader accepted an injected v3 `visual` record if the manifest claimed an older version. Reject visual fields in historical photo records. Update old synthetic migration fixtures and the Windows editor probe to remove v3 keys when constructing authentic v1 archives; test that legitimate v1/v2 projects still open and require Save As for v3.
- **PR19-F05 — MEDIUM — unchecked GUI mark capacity.** Drawing mark 121 hit the core limit only *after* mutating the dialog, raising an uncaught exception through a Qt handler. Check capacity before mutation and display a visible warning, preserving the prior layer and undo history.
